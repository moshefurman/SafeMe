# SafeMe Portal — מרכז הניהול

ממשק הפורטל. React + Vite + TypeScript, עברית RTL.

```bash
npm install
npm run dev      # http://127.0.0.1:5173
```

דורש שהשרת ירוץ במקביל על פורט 3000 (`cd ../server && npm run dev`).
ה-proxy של Vite מעביר אליו את `/api`, כדי שהפורטל והשרת יחלקו מקור
אחד ועוגיית ההפעלה תישלח כרגיל בלי להקל על `SameSite`.

## נתוני הדגמה

```bash
cd ../server && npm run seed:demo
```

יוצר משפחה עם שישה מכשירים במצבים שונים — מוגן, סינון חלקי, לא מסונן,
בנעילה, ומנותק. המגוון מכוון: קל לבנות מסך שנראה מצוין רק כשהכול ירוק.

| משתמש | תפקיד |
|---|---|
| `parent@demo.safeme.test` | בעל חשבון. נכנס בשלב אחד |
| `operator@demo.safeme.test` | מוקד. יידרש להגדיר אימות דו-שלבי |

הסיסמה מודפסת בסיום הזריעה.

## מבנה

```
src/
├── api.ts                 fetch עם CSRF וזיהוי דרישת MFA
├── types.ts               טיפוסים ותוויות בעברית
├── App.tsx                שורש, ניווט בין שני מסכים
├── components/
│   ├── Shield.tsx         המגן — אותו מסלול SVG כמו הסוכן
│   └── StatusChip.tsx     שבב מצב
└── screens/
    ├── Login.tsx          סיסמה, רישום MFA, והקלדת קוד
    ├── Dashboard.tsx      אריחי סיכום ורשימת מכשירים
    └── DeviceDetail.tsx   פרטים, ציר זמן, ופעולות
```

## שלוש החלטות עיצוב

**המגן זהה לזה של הסוכן.** מסלול ה-SVG ב-`Shield.tsx` הוא תרגום מדויק
של `ShieldRenderer.BuildShieldPath` ב-C#, באותה מערכת קואורדינטות.
גם ארבעת צבעי הסטטוס זהים. מנהל שרואה מגן אדום בצילום מסך של לקוח
רואה אותו אדום גם כאן.

**הרשימה ממוינת לפי דחיפות ולא לפי שם.** לא מסונן קודם, אחר כך חסום,
ורק בסוף תקין. מנהל שנכנס בבוקר רואה את הבעיות למעלה בלי לחפש.

**אין ספריית ניתוב.** שני מסכים בלבד, וספרייה נוספת כאן הייתה תלות
בלי תמורה.
